The fallback. Your password is hashed before it is sent, the way Qobuz's API wants it, and the plaintext is never stored — but the redirect above is still the better way, because this app never sees anything at all.

Import a library file

A CSV exported from Mandarin or any other music software. Each album in it is looked for on Qobuz and added to your favourite albums. One row per track works best: an album with no barcode is only accepted when its track listing agrees.

    Clear a library

    Remove favourites, albums, artists or playlists from your Qobuz library — to start again, or before importing into it. This cannot be undone, and Qobuz keeps no copy.
