MusicD Migrate

Move playlists, albums, artists and tracks between Qobuz and Spotify — or find your Roon library on either of them.

Connections

Qobuz

Sign in on Qobuz's own page. Nothing is typed into this app.

If the sign-in cannot redirect back — you are on a phone and this app is on a server elsewhere — copy the whole address from the page it lands on and paste it here.

Or sign in with an email and password

The fallback. Your password is hashed before it is sent, the way Qobuz's API wants it, and the plaintext is never stored — but the redirect above is still the better way, because this app never sees anything at all.

Spotify
Where do I get a Client ID?

Spotify has paused new app registrations. The Create app button on their dashboard is greyed out — "new integrations are currently on hold" — so the usual advice does not work at the moment.

Redirect URI — whichever route you take, this is the address to register:

This build has one filled in already, because a registration you cannot obtain is not a setup step. Know what it is: it is one of the well-known ids the open-source Spotify world shares, so the consent screen will name that application rather than this one, and the requests count against its quota. It works here because the address above is whitelisted on it.

  1. If you have a Spotify app of your own — from anything at all — prefer it; only new registrations are frozen. Open it on developer.spotify.com/dashboard → Settings → Edit, add the address above under Redirect URIs, save, then paste the Client ID below. A saved id always wins over the built-in one.
  2. If you don't, leave the field alone and sign in.

No client secret either way. Sign-in uses PKCE, so nothing secret is stored in this app.

Spotify only redirects to 127.0.0.1 over plain http, so a sign-in started from another device lands on a page that will not load. That is fine: copy the whole address from it and paste it here.

Roon

Your own library, read out of Roon and looked for on Qobuz or Spotify. One direction only — nothing can be written back into a local library, because the files would have to exist first.

Albums and artists, not tracks or playlists. A Roon browse row gives a title and an artist and not a track's length, and a title and artist alone are exactly what a cover, a re-recording and a live take all satisfy. Matching on that would quietly put the wrong recording in your library.

Or type its address

Discovery is a UDP broadcast, which some networks drop. The Core's address and port are in Roon under Settings → General.
